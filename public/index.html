[ 05 // FREQUENTLY INTERCEPTED ]

QUESTIONS FROM
THE UNDERGROUND.

DO I NEED TO INSTALL ANYTHING?+

No. Players use a modern browser. Whoever hosts the Sinatra server runs the Ruby app and configures the Gemini API key.

IS THERE A PLAYER LIMIT?+

Each room supports up to five operatives total, including the host. Share the private room invite link to bring in your crew.

DOES THE AI CONTROL THE DICE?+

No. The Ruby server rolls action checks and manual dice. The AI Game Master narrates outcomes, but cannot change authoritative roll results.

CAN WE PLAY WITHOUT AN API KEY?+

Yes. The server owner can switch on DEMO_MODE=true for sample scenes. Live AI-generated narration requires a working Gemini key and available quota.

WILL OUR CAMPAIGN BE SAVED?+

Rooms, character progress, and story state are stored on the host server. Existing session tokens allow a player to resume in the same browser while the room exists.
