[ 01 / QUICK START ]

GET THE CREW ONLINE.

  1. Choose an operative. Pick a handle and one of five archetypes. Different classes have different EDGE, GHOST, and TECH values.
  2. Create or join a room. A host creates a private eight-character code; friends join using the code or invite link. Maximum five players.
  3. Start the campaign. The host chooses Noir, Rebellion, or Ghost Signal, then starts the Game Master.
  4. Play a round. Each player commits one action, then MUST click ROLL 1D20. The GM cannot advance until every committed action has its required D20 roll. When the last player rolls, the GM resolves the round.

[ 02 / CORE MECHANICS ]

ROLL 1D20 + STAT.

Click COMMIT ACTION to queue your intent without rolling. A roll prompt appears immediately: click ROLL 1D20 to explicitly roll exactly one server-generated twenty-sided die. Your stat bonus is added, then the result is compared with the appropriate difficulty (DC 13–15). No roll is made automatically. The server will reject GM advancement while any committed action is unrolled.

Even a failed roll moves the fiction forward—sometimes with injury, stress, a new complication, or a harder choice.

[ 03 / SPATIAL PLAY ]

THE TACTICAL GRID.

The game shows a shared 14 × 9 map with numbered tokens for each active player. Click a tile to move your operative; movement uses orthogonal paths, up to four squares per move, and respects walls and occupied cells.

Hosts can paint terrain or regenerate the grid. Moving a token is a visual tabletop aid and doesn't consume your narrative action.

[ 04 / DICE TOOLS ]

ROLL WHEN YOU WANT.

Optional tabletop dice are independent of the required action roll. Rolling a D20 from this toolbox does NOT advance a pending action. Choose 1–8 dice, a die type (D4, D6, D8, D10, D12, D20, or D100), and an optional modifier from −20 to +20. Every result is generated by the server and posted to the crew datastream.

[ 05 / GAME MASTER ]

GEMINI WRITES THE WORLD.
YOU WRITE THE CHOICES.

The Gemini GM creates the current scene, NPCs, objectives, and consequences. It uses the existing campaign's world memory and the server's authoritative dice results. Hosts configure the API key once; players do not need their own keys.

Campaign state is saved on the server in data/rooms/. A browser stores its own session token so it can reconnect while the room exists. Back up the data directory before replacing the app.

⚠ This is a self-hosted MVP. A player who leaves an active room cannot necessarily rejoin that campaign with a new identity. Keep your browser's saved session if you intend to return.
